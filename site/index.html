Why VS Code plays your MP4 without sound

Open an .mp4 in VS Code and you get the picture, a seek bar, and silence. Nothing is broken on your machine — the editor genuinely cannot decode the audio.

The cause: a missing AAC decoder

VS Code renders custom editors inside a webview, which runs on Electron — and Electron builds on the open-source Chromium tree. That tree ships without the AAC decoder, because AAC is patent-encumbered and shipping a decoder means licensing it. Google licenses the codecs for the Chrome binary it distributes; the open-source build everyone else compiles does not inherit that.

Almost every .mp4 and .mov in the wild carries H.264 video with AAC audio. The video track decodes fine. The audio track has no decoder to go to, so a plain <video> element plays the picture and stays silent. No error, no warning — which is exactly why it reads like a bug in your setup.

Quick check: a .webm file plays with sound in the same editor. WebM carries Vorbis or Opus audio, which the open-source build does include. If WebM has sound and MP4 does not, you are looking at the codec gap, not a broken install.

How this extension works around it

Video Player (with Audio) is a free, MIT-licensed extension that sidesteps the missing decoder instead of waiting for it:

  1. The video file is served from a loopback HTTP server with Range support, so even large files stream rather than loading into memory.
  2. ffmpeg extracts the audio track to MP3 in the background — a format the webview can decode.
  3. The player shows a muted <video> next to a hidden <audio> element and keeps the two in step, correcting drift continuously so long clips do not slide out of sync.

What plays, and what needs ffmpeg

FormatAudioNeeds ffmpeg
.mp4 / .mov / .m4vExtracted via ffmpegYes
.webmNativeNo

.webm needs nothing installed. That covers Playwright test recordings, which are WebM — you can watch a failed test's video with sound without setting anything up.

For MP4, MOV and M4V you need ffmpeg on your PATH. If it is missing the video still plays, just silently, and the player says so and offers the command for your platform: brew install ffmpeg on macOS, winget install Gyan.FFmpeg on Windows, sudo apt install ffmpeg on Debian and Ubuntu.

Install

  • In VS Code, open the Extensions view and search for Video Player (with Audio).
  • Or run ext install yutabee.unmute-video from Quick Open.
  • For VSCodium, Cursor and other Open VSX clients, install it from Open VSX.

It registers as the default editor for .mp4, .mov, .m4v and .webm. Opening one of those from the Explorer is all it takes.
